# VISTA 实际评估记录模板

> 本文件是空模板，不代表测试已完成。公开前删去个人、客户和账户信息；保留判断所需的匿名证据。

- 日期与 skill 版本：
- 客户端与模型（不可见则写未知）：
- 用例编号 / 自定义真实任务：
- 会话条件：新会话 / 多轮续接（附必要上下文）
- 允许的工具与资料：
- 原始用户输入：
- AI 实际输出或脱敏记录位置：
- 学习者实际回答与产物：
- 帮助程度：独立 / 提示后 / 跟随示范 / AI代做
- 协议判定：通过 / 不通过 / 未执行（附可观察依据）
- 成果验收：达标 / 未达标 / 待验收（附标准与证据）
- 个人能力证据与暂定等级（不足则写尚未评估）：
- 情境：真实 / 模拟
- 延迟复测：未进行 / 间隔与实际新题结果
- 时间：学习 / 执行 / 等待（没有记录写未知）
- 失败或意外表现：
- 建议修改及复测结果：

不要只写“感觉很好”或“AI说通过”。行为用例合格与学习效果改善是两种不同结论，应分别记录。
