# vista学习法｜调用指令与输出模式

内部技能名：`vista-learning`；对用户展示名：`vista学习法`。自然语言调用语句仅在Skill已安装/已被客户端读取时可靠触发；部分客户端可以通过 `$vista-learning` 显式调用。

## 常用语句

| 用户说 | 预期行为 |
|---|---|
| `用vista学习法，教我在7天内做好一份目标岗位业务分析` | V 目标校准后逐步推进，非一次发完教材 |
| `使用vista学习法，快速建立电商用户增长认知` | 先选可验证场景或轻探索目标，快速模式 |
| `用vista学习法测试我对会员复购策略是否真的理解` | 直接以新情境应用题起步，逐题反馈 |
| `vista学习法，诊断我为什么学不会SQL` | 跳至故障诊断，识别知识/操作/资源障碍 |
| `vista学习法，复盘我刚做完的一次增长实验` | 先读真实行动和数据，没有就标记未验证 |
| `继续VISTA，以下是我上次的状态快照：...` | 读取快照，按上次卡点直接继续 |
| `VISTA深入模式：准备一次岗位业务方案答辩` | 增加机制、风险、反例和迁移，仍一问一答 |
| `VISTA，直接给我全部训练计划，不用一问一答` | 尊重用户，输出计划；勿宣称训练已完成 |

## 首轮回复示例

用户：`用VISTA学习法，我想学用户增长。`

合格：
> **VISTA｜V 价值定义**
> 用户增长是较大的领域。为避免先学一堆暂时用不上的知识，我们先确定一项真实任务。
> **你最希望通过这次学习做成什么？** 例如“分析一个产品首单转化率低的原因”，或“准备用户增长岗位的业务面试”。

不合格：先发“用户增长全套20讲”或者十个问题的问卷。

用户：`VISTA，我下周要面试用户增长岗位，我已做过私域运营。`

合格：
> **VISTA｜V→I**
> 暂把目标定义为：能围绕目标岗位，独立解释增长问题、提出策略、说明验证方式。你的既有私域经验可以直接用于诊断，无需从零学用户运营基础。
> **请贴一条目标岗位JD，或给我一个其核心职责**，我据此选择第一个业务情境题。

## 续学快照用法

- 每完成一个重要环节，在用户希望保存或需要切换对话时，用 `assets/session-state.md` 填写一份简洁快照。
- 任何时候用户贴入快照，先核对当前目标是否仍有效；直接处理未完成动作。
- 若用户要求导出真实文件且客户端支持写文件，可以将快照保存为 Markdown；否则输出可复制的 Markdown 文本，不虚构保存路径。
