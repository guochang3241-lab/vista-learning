# VISTA 学习阻塞诊断卡

## 故障路径：先诊断，再补课

| 观察到的症状 | 可能根因 | 最小修复动作 |
|---|---|---|
| 不知道为什么要学，持续变更主题 | V 的目标价值与验收不清 | 重写成当前必须完成的一份成果；与替代路径比较 |
| 查了很多资料却说不清结构 | I 从侦查滑向细节阅读 | 暂停收集，画5–7板块地图，留空白 |
| 地图庞大，选不出卡点 | S 的任务粒度过粗 | 把最近一步细化到30–60分钟可尝试的动作（只是启发式，不是必须耗时） |
| 知道问题但一直想多学一点 | 缺少“学习够用”的门槛 | 做一题新场景应用，能答就立即最小实践 |
| 学不会/查不到资料 | 提问不够具体或术语不匹配 | 改写成「情境 + 限制 + 明确问题」并查行业术语 |
| 学的时候会，动手不会 | 概念和操作之间存在距离 | 把任务拆成一个最小可见产物，边做边定位缺口 |
| 已做却不知道效果如何 | T 缺基线/指标/反馈 | 补一张验证卡；做可观察的小测试 |
| 得到了好结果，无法解释原因 | 证据不足或混杂因素 | 列替代解释，重复实验或设置对照 |
| 同类问题反复出现 | A 未抽象成规则 | 把3个相似案例合成一个条件式规则并测反例 |
| 只能在熟悉场景做对 | 迁移条件未理解 | 换一情景，明确相同机制和不同前提 |
| 同时学多个方向都没有进展 | 深度工作切换成本高 | 选一个主突破点，其他任务只做低强度侦查/等待反馈 |

## 切换路径的六类障碍

- **知识障碍**：不知道为什么/如何工作 → 有针对性的讲解与实例。
- **技能障碍**：知道理论但无法做 → 示范最小步骤、让学习者实操。
- **资源障碍**：缺数据、权限、工具、时间 → 找替代数据、借力或调整目标；不要盲补课。
- **决策障碍**：有多个可行方向不会选 → 比较机会、成本、风险，选可逆的一步。
- **验证障碍**：行动后没反馈或因果不明 → 先设计信号和对照，再决定是否学习。
- **情绪/行动障碍**：担忧不确定性导致拖延 → 缩小行动风险与范围，安排可逆小试验；不替代心理健康诊断。

## 升级与边界

- 同一缺口解释两次仍答不出：先排查前置概念或更合适的教学形式。
- 同一任务实践两次都没推进：考虑不是知识问题，回到S重新选路径。
- 数据源矛盾：标记证据冲突，不靠“更像正确”来裁决，寻找权威来源或等待核实。
- 医疗、法律、财务、安全等高风险任务：避免在真实环境里用未经验证的策略试错，先低风险演练和专业审核。
- 用户显然更关注兴趣探索而非任务结果：不要强制效率化；可以建立轻量探索任务，并提醒任务式学习的知识盲区。
