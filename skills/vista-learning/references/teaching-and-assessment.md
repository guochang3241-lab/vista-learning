# VISTA 教学与评估协议（进入 T 阶段时读取）

## A. 设计一次高价值教学回合

1. 获取用户已知背景；挑选一个影响当前任务结果的关键概念。
2. **先诊断**：从低认知负荷切入，让用户判断一个典型业务情境，别先讲完整标准答案。
3. 按错误所在进行 150–350 字「微讲解」：定义→因果机制→任务中的例子→易错边界。
4. 出一道与讲解不同、但可迁移的应用题；等待回答；如果用户索要答案，给答案并说明还未测出掌握程度。
5. 反馈时分四项：答对了什么、关键遗漏/偏差、为什么影响任务、下一道更窄或更深的题。每次不超过一题。
6. 有合格答复后，立刻尝试最小产物，避免无限补课。

## B. 诊断题与练习题类型

- **识别题（入门）**：指出一个具体案例的关键事实、概念和误区。
- **解释题（理解）**：为什么采用A，而不是B？说明因果机制。
- **决策题（应用）**：给现实限制，让学习者选择行动并说明代价。
- **反例题（边界）**：在什么条件下当前原则会失效？
- **迁移题（泛化）**：换产品/渠道/岗位/组织规模，怎么改原策略？

先辨认最需要哪种，不要每轮五题连发。对主观题给评价理由，不装作存在唯一正确答案。

## C. 评估等级与通过门槛

| 等级 | 行为证据 | 下一步 |
|---|---|---|
| L0 未建立 | 无法识别关键术语或明显误解 | 用例子重新解释、缩题 |
| L1 初步理解 | 能复述，但只能跟着熟悉例子答 | 换场景做解释/判断 |
| L2 能够应用 | 面对新问题做出合理选择并解释因果 | 进入小型实操验证 |
| L3 经验证可用 | 在真实行动中产生观察结果并复盘误差，能核验学习者的贡献 | 进入 A 阶段做迁移 |
| L4 可迁移 | 已有L3证据，又能在新情境说明适用条件/反例并完成新案例 | 形成可复用规则/知识资产 |

这些是**行为观察等级**，不是精密的心理测量，更不是模型给的客观能力证书。用户自主报告“我会了”仅能作为线索；如无真实行动结果，最高暂判L2，可另记“模拟迁移通过”。L3、L4只适用于已验证的能力与情境，不代表整个学科水平。真实完成度应视证据与目标而定。

每次结论同时标记：`能力/情境 + 等级依据 + 帮助程度 + 真实/模拟 + 即时/延迟`。不强行给证据不足的人评低分，可写“尚未评估”。结果成功但学习者解释不清，分别记“成果达标、个人能力待核验”。

## D. 验证卡：实践之前就设计验证

- **问题/目标**：当前尝试解决哪一个可观察问题？
- **动作X**：可复现的最小实践是什么？
- **预测Y**：预计发生什么、为何这么认为？
- **基线**：未干预时通常什么情况？无数据则写「基线未知」。
- **验证信号**：用哪个事实/指标/第三方评价检查？
- **替代解释**：哪些外部变化也可能导致相同结果？
- **实际观察**：真实看到什么？未执行/未回收数据则写「待验证」。
- **结论分层**：已观察事实 / 暂时推断 / 待验证假设。
- **修订动作**：下一轮如何验证更关键的不确定因素？

## E. 四类反馈环境

1. **快且客观**（如程序运行、算表）：使用明确测试输入输出、失败复现。
2. **快但噪声大**（如内容和增长）：对比基线、记录干扰因素，谨慎归因；可控时设计对照。
3. **慢且可观测**（如经营结果、复购）：设置中间领先指标和验证时间点，不能把领先指标当最终结果。
4. **慢且主观**（如写作、面试、管理）：在执行前约定评价维度，使用多人反馈/多轮场景测试，保留分歧。

## F. 失败与纠偏

- 回答偏离主题：指出偏离的是目标、机制还是行动，不要只说“再想想”。
- 连续答错：给一个小反例或对比表，再出一道更窄的新题。
- 直接背正确答案：换题核验，不重复原题判通过。
- 学习者回答优秀：省略基础知识，推进到执行/迁移，而不是继续夸奖。
- 由AI代写作业：只计为AI产物；需要学习者进行解释、修改或独立选择，才计入学习证据。
- 现实不可实操：使用纸面案例/模拟，标记「模拟通过，真实验证未完成」。

## G. 提示逐步减少与独立性

- **独立**：在事先约定的资料与工具条件下自行判断，未得到本题解题提示或答案。允许查文档的实务任务仍可独立完成，记录工具条件即可。
- **提示后**：AI指出方向或关键缺口后完成。保留证据，但不据此宣称无提示也会。
- **跟随示范**：照着示例改写。下一轮换数据或约束，再检验关键决策。
- **AI代做**：成果可用于交付，个人能力仍未验证；让用户解释、找错或修改其中一处关键决策后再评估相应能力。

初学者卡住时，先给方向提示，再给局部示例，最后才给完整示范；用户要求答案时可直接给。能完成后逐步减少帮助，不每题强迫从零重做。独立测试时先不提供答案；如需提供，结束该题的独立测评，换新题再测。

## H. 延迟复测与效果记录

即时答对只能证明本轮表现。对用户希望长期保留的核心能力，建议在有间隔的后续会话再做一题未见过的同机制应用题；时间由任务节奏决定，例如几天后，不能称为经验证的最佳间隔。

复测先作答再反馈，记录间隔、资料/工具条件、帮助程度及关键错误。遗忘时只补对应缺口，随后换题；迁移题改变情境和限制，不只替换名词。未复测写“延迟待测”，不自动降低原有即时成绩，也不宣称长期掌握。

若需检验VISTA本身是否有效，分别记录任务质量、耗时、提示次数、独立新题表现及延迟表现。前后题难度、工具权限尽量可比；单次前后改善仅为个案线索，不能据此声称方法优于其他教学方式。
